# 网页行情文档

在这个文件夹新增 Excel，即可生成独立的行情页面，并在网页顶部切换。

参数说明使用同目录、同名的 UTF-8 Markdown 文件：

```text
方案A.xlsx
方案A.md
方案B.xlsx
方案B.md
```

例如 `YDA价格汇总与每日行情.xlsx` 的说明应命名为 `YDA价格汇总与每日行情.md`。说明会显示在页面顶部、图表之前；没有说明时行情仍可显示。

文字加粗：在两侧各加两个星号，例如 `初始资金为 **20,000 HK**，修正系数为 **8**。`。

Excel 需要保留「价格发行与成交」「每日K线」两个工作表的现有格式。修改后提交并推送到 GitHub 的 `main` 分支，等待 Actions 发布成功。

同名文件覆盖更新会保留页面链接；新增文件生成新页面。这里只放准备在网页展示的文件。个人记录继续放在仓库的 `docs/` 中。
